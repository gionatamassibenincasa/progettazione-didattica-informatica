# Documenti di riferimento

Questa cartella contiene materiale di consultazione utile per compilare i dati in `data/*.yaml` — **non viene letta dal codice** (`src/genera_doc.py` non accede a questi file).

Puoi metterci ad esempio:
- Indicazioni Nazionali/Ministeriali per l'insegnamento delle discipline
- Documenti sui framework di competenze citati nei file dati (es. DigComp, CINI Informatica)
- Documenti target/di riferimento con cui confrontare l'output generato in `output/`
